# 🖥️ Lab Log: Account Initialization & Subscription Governance
* **Platform:** Cybr.com (Learn Azure in 30 Days)
* **Track:** Day 1 — Create Account, Subscriptions & Directories
* **Focus Area:** Cloud Governance & Tenant Segmentation

---

## 🎯 Lab Objective
The core objective of this deployment track was to initialize an enterprise-ready cloud footprint within Microsoft Azure, map tenant directories, establish subscription boundaries, and analyze cloud resource isolation models.

---

## 🛠️ Infrastructure Core Concepts Explored

### 1. Tenant Architecture & Identity Boundaries
* Explored **Microsoft Entra ID (Azure Active Directory)** tenant configurations to verify administrative isolation boundaries.
* Reviewed how global unique identity parameters lock down unauthorized directory access at the highest organization level.

### 2. Subscription Management & Cost Isolation
* Evaluated the logical boundary framework of **Azure Subscriptions**.
* Analyzed how subscriptions separate distinct business billing models, track asset limits, and map to isolated corporate accounting parameters.

---

## 📈 Governance Optimization Review (PMP & Six Sigma Alignment)
* **Resource Isolation Strategy:** Grouping cloud footprints into specific directories ensures strict security compliance and reduces risk vectors.
* **Fiscal Control Operations:** Isolating cloud spaces into dedicated sandbox environments allows for targeted cloud cost optimization and keeps resource spend transparent.
