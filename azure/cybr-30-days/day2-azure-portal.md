* **Platform:** Cybr.com (Learn Azure in 30 Days)

* **Pillar:** Cloud Governance & Tenant Operations

---

## 🎯 Lab Objective
The core objective of this deployment track was to initialize a secure cloud sandbox footprint inside the Microsoft Azure portal engine, evaluate tenant resource hierarchies, and analyze control plane activity logs.

---

## 🛠️ Step-by-Step Architecture Execution

### Phase 1: Portal Navigation & Directory Exploration
* Audited the primary Microsoft Entra ID (Azure Active Directory) tenant properties to verify administrative domain parameters.
* Inspected administrative roles and verified resource access structures across organizational boundaries to ensure proper perimeter controls.

### Phase 2: Resource Hierarchy Management
* Created a targeted **Resource Group** (`rg-lab-governance`) to enforce baseline lifecycle management constraints.
* Applied explicit cloud tagging metrics (`Environment: Lab`, `Owner: Rabindra`) to simulate enterprise resource tracking and cost auditing.
